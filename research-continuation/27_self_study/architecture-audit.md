## Executed architecture path

`StudySession → RequestSession → ConstraintRuntime → continuing inquiry/session`
restores the qualified predecessor. `StudyR1.attach` extends that exact owner in
place with two registered numerical maps. The typed solver, neural route,
session, base request route and legacy learner hold the same owner object.
Verified examples alter retained operator parameters; language examples alter
the continuing request parameters. Existing legacy facts and reusable programs
are rebound and revalidated after parameter-owner changes.

A failed goal certificate triggers the bounded source route. The arXiv adapter
stores source bytes and identity, the supplied table reader proposes claims,
two independent checks decide admission, numerical weights update, and the
original task is retried. The durable record holds the source budget, ordered
lesson IDs, exact original task, practice outcomes, failed claims and restored
weights. Independent tests show a resumed lifetime matches the uninterrupted
lifetime after an explicit two-lesson interruption.

This is the local actual-owner successor to the source-to-capability interface
requested by v11. I did not replace the existing architecture with v11's
standalone lab. The original `ImprovementPolicy` remains in the predecessor;
this bounded route uses a fixed goal-filtered schedule whose contribution is
labelled as engineering. The selector itself has no new learned-policy verdict.

## Boundaries maintained

Learning changes retained weights; a source fetch alone does not. A verified
mathematical identity is distinguished from an observed event or physical model
assumption. Propagation, conditioning and learning keep their previous contracts.
The new numerical certificates do not widen the existing GG-GUARD applicability
gate, which remains domain-specific. A shared owner is directly tested; positive
cross-route transfer requires its own measured task comparison.

The language curriculum supplies annotated requests in known intent categories.
The mathematical curriculum supplies coefficient semantics and a bounded reader.
The benchmarks therefore establish the measured learned mappings and executable
behavior within those contracts. The next research steps expand these contracts
through training and fresh assessment rather than making unmeasured verdicts
about general capability.

The source-correction experiment demonstrates an admitted derived identity,
retained numerical learning and fresh transfer. The proposer/checker were
engineered. The RH parent remains the original universal statement; a finite
polynomial result is recorded as a prerequisite with its own exact scope.
