## Actionable findings

1. **The runtime cap admits work but cannot stop it.** `study.py:163` reserves 25 seconds before `run_case`, then refunds the difference after completion. There is no supervisor or timeout around the call. An interrupted or hung case can consume more than the reservation and exceed the claimed cumulative cap. This primary cohort completed in 207.2694975 charged case seconds, below its 900-second limit; no actual overrun was observed. Preserve its measurements and describe the mechanism as a soft admission budget. Future workloads need an external supervisor, an enforced remaining-time deadline, and interruption accounting. The original `running` marker correctly refuses to silently resume an incomplete case.

2. **The artifact has a mixed codec, and decoding uses float64 arithmetic.** `core.py:219` marks the entire artifact `float32`, but class probabilities, noise variance, calibration variance, log evidence, and guard bounds retain float64 values. Only the coefficient/covariance arrays, neural weights, coordinates, observations, and residual arrays are explicitly quantized. `network_predict` and other decoders then compute in NumPy float64. All 721,572 claimed float32 parameter scalars across the primary cohort were exactly float32-representable; the issue is the broader metadata claim. Report the mixed precision and score from the preserved decoded representation. Do not retroactively quantize the primary models.

3. **Initializer seeds expose an invertible transform of simulator seeds.** `study.py:64` calls `fit(..., initialization_seed=seed + 50000)`. Thus the literal protocol claim that simulator seeds are absent from the fitting API is too strong. The inspected implementation uses this argument only for `torch.manual_seed`; it imports no simulator and does not invert or exploit the seed. No realized seed oracle was found. The correct boundary is trusted inspected code, not an API that cannot receive seed information. A fixed initializer or independently frozen initializer assignment can remove this arithmetic coupling in future cohorts.

4. **Original peak memory was unavailable, and numerical payload was omitted from the initial aggregator.** The primary and smoke states explicitly contain `peak_working_set_bytes: null` with `psutil unavailable`; they cannot support a measured original memory claim. A separately labeled supervised refit can report its own peak memory, preserving the distinction. Exact full artifact JSON totals 19,401,037 bytes in the primary cohort. An independent inventory also records 39,196 float64 scalar fields and separately counts integer fields and numeric JSON lexemes. A hypothetical packed representation of just these floating values would occupy 3,199,856 bytes; this is a counterfactual numerical payload, not a deployed artifact or an integer/schema/decoder/runtime cost. The complete JSON remains the actual object cost.

5. **The initial replay's independent mathematics cover only part of the uncertainty calculation.** `audit.py:88` independently solves posterior means using augmented least squares, but covariance is checked only for positive semidefiniteness, while evidence, family probabilities, and calibration inflation are not independently recomputed there. Its metrics replay calls the same `core.metrics`; MSE and interval coverage have additional independent calculations. The reference unit test independently checks mean, covariance, and evidence for one circle instance. The supplemental checks below fill the covariance/evidence/NLL gap across the completed cohort. Candidate search choices, the complete neural optimizer trajectory, calibration construction, and every feature interpreter are still not independently implemented by this review.

6. **The frozen identity is not a complete evaluator boundary.** The run hashes `__init__.py`, `core.py`, `data.py`, and `study.py`, plus protocol JSON. Tests, the fresh-process auditor, and the aggregator have separate identities rather than belonging to that initial source identity. That boundary is suitable for a disclosed same-source replay. It should not be called an independent implementation or a fully frozen external evaluator. The existing auditor checks the expected case and method set, but iterates the recorded evaluation partitions rather than asserting their fixed four-name set; a future verifier should assert that set explicitly. The supplemental review confirms that all 20,480 actual partitions are present.

## Positive mathematical and lifecycle checks

The fit API receives copied observed coordinate/value banks with support, selection, and calibration roles. It rejects query-role training, imagined or predicted observations, nonfinite rows, and exact role overlap. The complete primary banks were compared directly: support coordinates, noisy outputs, and clean audit targets nest exactly over 8/16/32/64 observations, and the selection/calibration banks remain identical within each seed/family/noise condition. No float32 coordinate collisions occur within or between the primary support, selection, calibration, and held-out query banks. These checks address actual data, not only a generator design assumption.

Every case saves all eight artifacts before generating its independent query banks. The raw clean targets in assessor archives are not passed to `fit`. Saved artifacts are decoded before scoring and hashed again afterward. The design is a trusted-process separation: role flags and module boundaries do not create a security sandbox against hostile Python code.

The constrained circle design has four coefficients and a constant radius. The equal-prior mixture uses the correct linear-Gaussian marginal likelihood under a coefficient prior with variance four and the supplied observation noise. That is a posterior under its declared prior/menu, not necessarily the exact posterior under the simulator's center/radius distribution. Mixture variance includes between-model dispersion. Marginal NLL correctly averages univariate mixture log densities, rather than claiming a joint two-coordinate likelihood. Interval coverage is explicitly for Gaussian-moment intervals, whose 95% label is not a distribution-free coverage guarantee.

E and G/H select finite supplied expressions with a frozen selection-MSE penalty; this is selection in a language, not unrestricted representation discovery. C/E/G/H coefficient covariance omits uncertainty over the selected structure; H also omits uncertainty over residual estimation. Calibration adds a nonnegative empirical variance term and an in-region alarm. It provides no guarantee in unobserved regions and no learned semantic applicability test. The stored general guard is descriptive; the H residual alone has an operational restriction to its stored coordinate range. Known noise, phase, function primitives, and decoder machinery are supplied prior information.

## Supplemental independent numerical checks

The read-only supplemental audit checked all 4,480 serialized linear components and all 20,480 query partitions without optimization, retraining, candidate selection, artifact mutation, or another checkpoint bank.

- Every posterior mean and covariance agrees with an observation-space Gaussian calculation at fixed `rtol=3e-6, atol=2e-7`, allowing the documented float32 parameter codec. The maximum absolute differences were 1.6990411e-6 and 1.1734263e-7 respectively; the larger coefficient error passes the relative criterion.
- Every independently computed marginal mixture NLL agrees at the original replay `rtol=atol=1e-12`; maximum absolute difference is 9.0949470e-13. The reference uses `logaddexp.reduce` and exact zero mixture weights, separate from the decoder's implementation.
- The initial dense observation-covariance Cholesky comparison failed the existing reference test's absolute evidence threshold of 1e-7 for 197 component records. Its maximum discrepancy was 1.2205855e-6. Those covariance matrices had condition numbers of approximately 149,582 to 1,025,941. This diagnostic remains saved with `FAIL`; it was not erased or relabeled.
- A follow-up thin-SVD observation-space reference avoids the ill-conditioned dense covariance calculation. At the **same** 1e-7 evidence threshold, all 4,480 components pass; maximum evidence difference from the artifact is 7.1013346e-9. All 640 D-family posterior weight vectors agree with the SVD evidence calculation, with maximum absolute difference 1.0416112e-12. This isolates the initial discrepancy to numerical limitations of that reference calculation, rather than establishing an error in the fitted model formula. Both references share the frozen feature/design interpreter, an explicit independence limit.
