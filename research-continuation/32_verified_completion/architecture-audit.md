# Connection to the continuing architecture

The extension attaches `CompletionR1` in place to the existing GroundR1 object. Grounded definitions, human reading, request interpretation, exact mathematics and empirical refinement retain their original tensors. The new `completion_policy` parameters choose among permitted investigations and STOP; each `completion_clouds` module retains a joint mean and covariance for an individual original goal.

The learned selection policy receives public numerical uncertainty and cost features. It does not receive the hidden mechanism, audit answer or all-action reward table. The environment and reward definition are engineered; reward updates teach the policy which choices are useful. Practice on the same finite training worlds is counted as repeated exposure.

Imagination samples one complete mechanism per branch. That same mechanism supplies the acceleration used by the actual StudyR1 integration operator at both query times. The independent rational checker validates the calculation under the explicitly fixed acceleration assumption. The branch remains a conditional completion.

Only the qualified source boundary supplies acquisition and independent audit receipts. Reward uses frozen before/after predictions and a separate audit. It modifies the registered selection policy, not the acquired observation history. The credit record binds original goal, policy, decision, predictor versions, source identity and acquisition set. An audit identity belongs to the source event, so changing a task name cannot earn another reward.

Source search and the 26 taught physical meanings remain on GroundedSession. The novel-definition gate stays closed. The retained momentum task and its arXiv references are preserved; this numerical completion interface does not relabel momentum as an already admitted acceleration definition.

The scope is a supplied conditional numerical family. Broader source interpretation, mechanism invention, learned source-quality estimates and successive improvement of the learning algorithm remain separately testable work. No finite result is interpreted as a general impossibility claim.
