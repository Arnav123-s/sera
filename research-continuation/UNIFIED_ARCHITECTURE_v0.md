# Unified architecture v0 — implementation target

I retain the decomposition `(K, theta, eta, z, E, A)`: executable knowledge, a declared shared numerical owner, investigation policy, current situation, admitted working evidence, and the preserved audit archive.

SERA's actual `SharedR1` remains the numerical ownership anchor. Parameter-free views reference it. A mechanism has typed ports, full content and interpreter identities, evidence obligations and dependency versions. Kavi contributes this executable-configuration organization; its phase vectors are not equated with SERA latent vectors.

The generator object contains a bounded executable expression or program, learned constants, its supplied input schema, empirical applicability, parameter and class uncertainty, residual witnesses and provenance. Several explanations describe the same observations. Their normalized weights remain conditional on the supplied menu; a residual alarm can mark the whole menu inadequate.

An investigator chooses a permitted observation or bounded internal calculation from the unresolved frontier. Predictions and hypothetical branches use the same versioned definitions. Only newly observed, eligible evidence can train factual knowledge. Imagination is explicitly conditional and must not alter the live record.

Consolidation proposes a reusable definition and checks its declared domain. Replacement invalidates dependent shortcuts transactionally. Active state either migrates under an explicit schema mapping, rebuilds from admitted observations, or rejects the revision. Keeping an old error is not retention.

A policy change is evaluated with old/new K crossed with old/new eta. Shared positive transfer, learned applicability, useful imagination and repeated policy improvement each require their own tests. None follows merely from this interface.
