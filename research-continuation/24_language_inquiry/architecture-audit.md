# Audit against the original architecture and v5

I re-read the original ZIP's editable handbook at SHA-256 `2371a18a074680d147f1f43cb7ffca2c0970d3dc2a08bccc095c1f71a688b528`, particularly lines 85–105, 422–447 and 893–913, and compared this implementation with the adopted v5 continuation. The original ZIP, PDFs, earlier addenda and all previous results remain preserved. V5's older repository snapshot does not override newer valid local work.

| Requirement | Current implementation and evidence | Remaining boundary |
|---|---|---|
| One shared R1 owner | InquiryR1 extends the preserved TaskR1; the language path calls the actual `shared_step`; typed, neural, interaction and numerical routes share object identity | Protected interface learning does not establish positive neural transfer |
| Typed inputs, state and outputs | Bounded text spans and sensor/control inputs; persistent inquiry progress; typed position/velocity results with units and evidence kind | Supplied grammar, one explicitly bound entity and three controls |
| Parameterized transition/readout | Existing recurrent path encodes spans; learned interface selects types/actions; registered interaction posterior drives conditional rollout | Kinematic form and posterior rule are supplied |
| Learning operator | 13 supervised meanings, one later word correction, sequential position/action updates | No semantic learning from world feedback; no general reading curriculum |
| Validity tests | Exact finite interpretation checks, independent consequence arithmetic, adversarial restore tests and conditional labels | No inherited physical applicability certificate |
| Computational costs | Full owned-job wall/memory receipts, labeled exposure, action/sensor counts, cache and restore work | No complete FLOP, energy or total research-efficiency claim |
| Separate state, parameters and procedure | Progress and memory change at query time; interface/dynamics change from labeled evidence; eta stays fixed | Accumulated knowledge is not learning-to-learn |
| Actions enter predictions | Signed controls affect the learned angular transition, and one completed request performs an authorized simulator action | Simulator-only authority; one action before new observation/reconsideration |
| V5 A03: language–interpretation–investigation connection | Learned span meanings form explicit ordered frames, dependency references and conditional computations from the same continuing situation | Binding and composition are engineered |
| V5 A04: competing language mechanisms | Three recurrent seeds and three matched bag controls, supplied-formalization and ignored-language controls; unsupported/ambiguous wording retained | Supplied syntax explains compositional transfer; no COGS or open-English claim |
| V5 A05: preserve deep unfinished work | Pause, reload, clarification, historical/current distinction, explicit rebase and retained failed requests | Fixed bounded action investigations, not autonomous scientific projects |
| V5 A06: reuse and local invalidation | Exact prefix cache, preserved historical versions, parser/core and dynamics dependencies, unaffected numerical-head control | Exact reuse is not acquired abstraction |
| V5 A07: acquire evidence and diagnose mismatch | Fresh sequential hidden-state worlds, observed correction and separately measured semantic/forecast errors | Fixed probing schedule; omitted mechanisms and broad extrapolation remain unresolved |
| V5 A08: learned executive | Fixed round-robin allocation is explicit and charged | No learned scheduler or hypothesis-construction policy |
| V5 A09: applicability and plasticity | Existing GG-GUARD-002 preserved; new forecasts uncalibrated; one correction retains 13 meanings | A new independent calibration and longer task streams are required |
| V5 A10: successor learning | No eta update or successor-generation claim | Old/new K crossed with old/new eta remains future work |
| Handbook promotion rule | Available as a restricted empirical engineering route after retention/integrity checks | Twelve worlds and three optimization seeds do not establish the handbook's general statistical self-improvement criterion |

The reference rotor/associative/low-rank core is inherited rather than replaced with a parser ensemble. No full learner is allocated to each interpretation. Independent experimental lifetimes use separate copies for assessment; the usable store retains one actual owner and versioned dependencies.

The principal architectural deviation is intentional and explicit: semantic roles and grammar are supplied, while only a small phrase interface is learned. Physical consequences are produced by the existing learned analytic interaction buffers, not by a newly learned universal recurrent world representation. The connection is real and tested, but a shared situation plus protected heads is not the full unified learning goal.

An import/style migration is parameter preserving and explicit. Old source archives, checkpoint bytes, owner identity, historical results and interrupted work are retained. It is an engineering compatibility operation, not new learning or a repeated experiment.
