## Use the saved successor

```powershell
.venv/Scripts/python.exe scripts/run_structural_persistent.py --output runs/my-field-batch-001 --module scripts.sera_current -- --input research-continuation/46_structural_refinement/example-tasks.json --output runs/my-field-results-001.json
```

The example batch predicts a changed state, imagines a trajectory, compares controls against a target, explains the evidence behind its chosen representation, and executes the earlier practical and four-language requests. Every result identifies its owner and model. Outputs are saved in a fresh local directory.

A fresh checkout first runs `python scripts/restore_current.py` after the [documented environment setup](../../docs/REPOSITORY_MAP.md#setup-and-verification). This restores the complete predecessor chain with its existing integrity checks. On Linux use `.venv/bin/python -m scripts.sera_current --input ... --output ...` with the same task file; the Windows resource supervisor remains available for the managed local research workspace.

| Request kind | Required fields | Result |
| --- | --- | --- |
| `field_what_if` | `subject`, `state: [qx,qy,vx,vy,ux,uy]` | Conditional acceleration, model identity, evidence scope and original goal |
| `field_trajectory` | `subject`, `state: [qx,qy,vx,vy]`, `control: [ux,uy]` | A fixed-model trajectory with explicit horizon and scope |
| `field_plan` | `subject`, `state: [qx,qy,vx,vy]`, `target: [qx,qy]` | Five imagined control choices and the best qualified branch for that target |
| `field_explain` | `subject` | Both candidate coefficient sets, independent comparison and the retained qualification |
| `field_findings` | none | All subjects, original goals, evidence counts and next actions |

State uses metres, metres per second and input acceleration in metres per second squared. The tested observation region has each position/velocity component between -1.5 and 1.5 and each input component between -0.5 and 0.5. Predictions beyond the assessed region remain explicitly conditional extrapolations. The trajectory command uses RK4 with a stated time step; its result preserves the fitted mechanism throughout the branch.

## Learn through attributed observations

`FieldSession.start` creates an original goal and source-bound subject. `observe` updates its radial and directional force weights from a typed measurement or explicitly simulated observation. `investigate` commits each chosen probe, obtains its response, preserves interruption state and requests separate selection and adequacy evidence. `qualify` independently replays the acquired coefficients and compares the candidate representations. A model update invalidates earlier branch views and requires fresh assessment before reuse as a qualified field.

The potential's integration factors are executed through the existing learned integral operator. A control reads the inherited R1 recurrent memory rather than installing another recurrent core. The structured geometry, typed variables, acquisition rule and independent assessor are supplied engineering; observations determine SERA's retained physical coefficients and the independently supported model choice.

An empirical force estimate and an exact polynomial calculation retain their respective evidence types. The source applicability gate and earlier exact denominator guards remain part of the same owner.
