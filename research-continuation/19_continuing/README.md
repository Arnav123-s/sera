## Task and mathematical contract

The continuing simulator supplies two-dimensional position measurements, the executed action and a public target schedule. Phase, velocity, actuator response, reversal time and family labels remain assessor-only. There is no reset action. The initial three measurements and two coasting transitions are paid; later target changes do not reset the learner or world.

The physical law is supplied: `v[t+1] = clip(rho*v[t] + gain*u[t] + drift + omitted_force, -.65, .65)` and `angle[t+1] = angle[t] + v[t+1]`. The source circle's center/radius come from actual acquired generator coefficients. The ordinary family reverses actuator gain once. The stress family additionally applies an omitted angle-dependent torque. A controller selects `u` from {-1, 0, 1} to track changing target positions with action and velocity penalties. This is a bounded intervention task; the grammar, coordinate units, actions and objective are engineered.

Three linear action-dynamics coefficients and their covariance are updated from observed transitions in registered float64 buffers of the same R1 owner. Existing neural parameters and original generator buffers remain fixed. The estimator uses a 12-transition window. A large pre-update innovation starts a new sufficient-statistic segment; all factual history remains preserved. The detector is engineered eta, not learned learning-to-learn. Angular wrap inference assumes changes below pi; no arbitrary alias-resolution claim follows.

The planning controller enumerates 81 four-action sequences using seven positive-weight parameter quadrature points. It executes the first action and replans after the next real observation. Conditional trajectories cannot enter the factual channel. Plans bind the actual tensor mutation versions as well as the state revision. Restoration reconstructs all dynamics from the factual log and preserves cumulative observation/action charges.
