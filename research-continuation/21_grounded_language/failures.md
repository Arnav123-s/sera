# Preserved failures and limits

- **Short development pilot:** 80 steps with batch 16 reached 23.63% exact translation on familiar development wording. Its weights, optimizer states, protocol and raw outcomes remain in `L10-PILOT-001`. The later development run changed seed, batch size and training duration; it is not an isolated causal test of extra steps.
- **Unseen sentence structure:** the longer development candidates reached 100% on familiar structures and 0% on both new structures. Confidence filtering accepted these failures. Final unchanged-core models average only 2.80% before a structure lesson. No unrestricted language claim is promoted.
- **Shared-core interference:** final shared-core adaptation loses up to 35.94 percentage points in an old capability group. These candidates remain in the archive and are not substituted for the live core.
- **Forgetting within language:** new-structure lessons reduce earlier wording accuracy to 37.30% on average in the interface condition. The continuing application withdraws failed forms and acquires them again on request. Recovering a specific requested form does not establish that every old form is simultaneously retained.
- **Empirical guard failure:** five wrong interpretations pass the original final wording guard. Independent arithmetic correctly verifies the wrong statements, so arithmetic validity alone is insufficient. `CONTRACT-001` preserves the original admissions and shows the corrective supplied-language check rejecting them. Its zero accepted errors are a finite contract result, not a general statistical guarantee.
- **Restricted vocabulary and teacher:** `scale` is a preallocated withheld token; examples, number meanings, operation grammar and update procedure are supplied. There is no demonstrated acquisition of an arbitrary new vocabulary or tutorial.
- **No established prior-training advantage:** all three conditions learn the familiar task. Recurrent-state dependence and common ownership do not establish positive transfer from earlier knowledge.
- **No learned eta:** the curriculum, AdamW settings, lesson selector and admission policy remain engineered. The separate A09 eta rejection stays unchanged.
- **Old full-suite timeout:** the preceding release's 80-second timeout remains untouched. This continuation has a clean 241-test full run, followed by separate tests for the added contract and current integration.
- **Host upgrade cleanup:** the verified old launcher exited with its owned server before a redundant cleanup call reached it. The resulting "process not found" message did not affect another process or the saved workspace; the current pointer hash was identical before and after the upgrade.
- **Viewport verification:** the initial browser resize call did not change the measured viewport. `resize-attempt.png` preserves that attempt. The actual mobile check used a measured 390-pixel emulated viewport; it is recorded separately in `mobile.png`.

No completed experiment was restarted or overwritten. The original L11 runtime sources are archived before adding the stricter output contract, so its original behavior remains reviewable. All local costs are retained, including development, controls, verification and corrective checks.
