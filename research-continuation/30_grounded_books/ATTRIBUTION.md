# Source attribution and handling

Original human prose is distinct from the engineering labels, numeric tests and model outputs. No claim of human authorship is inferred merely from a folder name.

- Webster's Unabridged Dictionary, Project Gutenberg ebook 29765: original complete dictionary entries and selected contiguous sense spans. Preserve the downloaded Gutenberg notice and historical usage context.
- W. M. Baskervill and J. W. Sewell, An English Grammar, Gutenberg 14006.
- Plato, The Republic, Benjamin Jowett translation, Gutenberg 1497.
- René Descartes, Discourse on Method, John Veitch translation, Gutenberg 59.
- Silvanus P. Thompson, Calculus Made Easy, Gutenberg 33283. TeX was parsed as text and never executed. Language windows exclude mathematical expressions; the original file preserves them.
- Yanran Li and colleagues, DailyDialog (2017), [paper and original supplementary archive](https://aclanthology.org/I17-1099/). Original dialogue partitions were retained. The downloaded archive README did not provide an explicit license; a source-intake field contains a provisional CC BY-NC-SA 4.0 description from mirrors, not verified permission. Raw dialogues and derived dialogue windows are kept local and are not included in the public runtime archive.
- Fatih Gozuacik, Denise Pattison, Catherine Tabor and OpenStax contributors, Physics, Rice University/OpenStax, [publisher](https://openstax.org/details/books/physics), [source](https://github.com/openstax/osbooks-physics), pinned dfdfd7a5356ecdd42e504de3df50d9153e33ea49. Original publisher content is CC BY 4.0. The runtime teaching bank retains original glossary meanings plus engineered labels and partition metadata; the applicable original license is included as OPENSTAX-PHYSICS-LICENSE.txt.
- Paul Peter Urone, Roger Hinrichs and OpenStax contributors, College Physics 2e, Rice University/OpenStax, [publisher](https://openstax.org/details/books/college-physics-2e), [source](https://github.com/openstax/osbooks-college-physics-bundle), pinned fd1b25dfd5d8c6580c6e2b2b34a19e29cc69ada9. The fetched repository LICENSE specifies CC BY-NC-SA 4.0; it is preserved as COLLEGE-PHYSICS-LICENSE.txt. Its final definitions remain a separately identified source cohort and are not added to the executable teaching bank.

The source manifest is an immutable acquisition record; this note corrects the uncertainty of its provisional DailyDialog license description without rewriting it. Modern machine-generated catalogue summaries were excluded. Newly retrieved arXiv papers are reference evidence, outside the human-only teaching curriculum. Public receipts retain paper identities and hashes rather than reproducing lengthy extracts.
