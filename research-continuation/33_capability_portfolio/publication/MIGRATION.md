The first direct script invocation exited before mutation because the repository root was absent from Python's import path (ModuleNotFoundError for workbench; command wall time 0.2476954 seconds). The original helper is preserved in migration-before.py.txt. The repaired helper resolves its own repository root before importing storage. This is file and metadata work, with no numerical training or new resource grant.

The migration verifies every copied file, including the private key and ledger, checks that model/optimizer/evidence fields remain identical and verifies the learner's append-only history.
