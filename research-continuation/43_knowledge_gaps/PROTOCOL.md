# KG-001: self-identified gaps in retained knowledge

The latest user direction is to let SERA find gaps in knowledge it already has, without a supplied target, missing-force label, answer equation or new teaching examples. This cycle begins at owner `91f6c21ffcf80e8aab05ca8eea8e34499a27803cd823aa5a087839ac44957230`. Earlier evidence, failed studies and source gates remain intact.

## Autonomous problem formation

The implementation enumerates the actual owner's retained equation records, scoped language associations and observed-source records. It derives potential investigations from disagreements, incomplete source coverage and unresolved qualification. An observation's recorded source row count and already-consumed row IDs make coverage gaps detectable without naming the missing mechanism. A fixed transparent acquisition priority ranks executable evidence gaps; the source and the target are not command-line inputs. SERA reads only already-retained source bytes identified by their existing SHA-256. No new corpus, supplied dynamics family or teacher response is introduced.

Existing final-evaluation rows are excluded from this study. Previously consumed calibration rows are also excluded from new scores. For newly investigated rows, SHA-256(source identity, row identity) assigns 60% to development, 20% to independent credit and 20% to final evaluation. Credit/final values are never passed to the search procedure. These are reserved rows of an already downloaded source, not a new independently collected experiment.

## One substantial finite study

Three procedures each investigate up to 4,096 distinct candidate programs in one resumable run: learned proposal ranking, residual-guided ranking, and balanced exploration. A program is built from the owner's retained learned polynomial integration operator, arithmetic and generic conditional branches. Search can alter degree, introduce or remove a condition boundary, and move a boundary. No bounce, launch, drag, hidden-force or answer-program template is supplied. Maximum degree is four; at most five boundaries; each fitted segment needs at least degree+2 development samples. A finite attempt ceiling of 131,072 per procedure terminates an exhausted grammar without pretending duplicate proposals are discoveries.

Fitting and three-fold out-of-fit development prediction use only development rows. Each candidate and its predictions are committed before separate assessor scoring. The learned ranker updates from verified development loss reduction. These repeated development scores guide search and are not counted as new factual evidence. Source identities, every candidate, invalid fits, repeated proposals, fit counts, optimizer/RNG state and elapsed costs are preserved. Checkpoints every 128 distinct candidates resume the same study. This is a large candidate search over existing evidence; candidate count is not a count of independent observations.

The maximum-eight portfolio is selected before opening credit or final data using development prediction loss, program complexity and genuinely different branch/continuity assumptions. Near-identical predictions with the same assumptions are aliases. A shared evidence-coverage reward gives credit only for independently accurate improvements over the retained model; each source-row contribution can be credited at most once across all candidates and all procedure comparisons. Different names and repeated successes add no credit. No points change source permissions.

## Controls, selection and one-shot evaluation

Controls are the unchanged retained predictor, a refitted same-degree model, degree-zero through degree-four global regressions, piecewise linear interpolation, and an exact dynamic-programming segmentation search on development data. The main procedure is selected by its best development score before any credit/final values are read. Controls and all three procedure portfolios are then evaluated once on the same reserved rows. Selection is not changed after final access.

A selected candidate is admitted as a scoped empirical prediction if its final RMSE is below half the unchanged predictor's RMSE and below max(0.05 in source units, 0.10 times development target standard deviation). Existing-source-domain checks remain separate from extrapolation. The final does not train coefficients or policy weights. The best analytic control is reported even if stronger. Several surviving models are alternative empirical explanations; a fitted residual does not identify an unmeasured physical cause.

Independent replay evaluates every committed development prediction, computes final errors using a separately implemented scalar evaluator, checks resumability, duplicate/stale/forged credit rejection, the actual owner identity, inherited tensors and the closed source gate. Only supported models are registered on the actual successor owner. Failed candidates, unqualified alternatives and open goals remain saved.

## Resources and scientific provenance

One CPU worker/thread, 2 GiB process-tree committed memory, at most 900 seconds per supervised job, no paid services. Standing approval is in ../RESOURCE_POLICY.md. Wall time, reservations, failures and resumptions are charged. No old completed experiment is rerun. Mathematical search and fitting are engineered; program choices, coefficients and proposal-ranking updates are the learned outputs.

Sparse equation search is compared with explicit structural search because sparsity depends on the candidate representation. The engineering reference is Brunton, Proctor and Kutz, *Discovering governing equations from data by sparse identification of nonlinear dynamical systems* (2016), https://robotics.caltech.edu/wiki/images/a/a3/BPK_PNAS.pdf. That reference informs implementation only; its equations are not passed to SERA as targets. The existing laboratory source identity is inherited from the owner and recorded by preparation.
